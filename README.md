# 听个响 · I Hear It

**你继续，俺在听。**

目前需要配合 **Kdenlive 工程**使用，其他剪辑软件和独立音频检索暂时还没接上。

其实这个工具的思路挺直白的：找几段声音当样本，分好类，然后去工程音轨里，找找还有哪些听起来差不多的声音。碰上容易认错的，也可以补几个排除样本，说明一下“这个虽然像，但不是要找的”。

至于具体找啥，主要还是看你给的样本。啧嘴、清嗓、笑声，或者某个有特点的音效，都可以拿来试试。分组自己建，样本随时能增删，用着觉得不合适就再调整一下。

找到的片段会列出来，可以直接试听，也能放大波形、拖动选区，细听一下到底是不是那么回事。确认之后，顺手标到工程里，或者直接裁掉。裁切会留下空白，后面的片段不动，写入前也会备份，改错了还能撤销。

当然也别指望给一个样本，就能把所有声音分得明明白白🤣。样本选得好，确实能省不少事，但筛出来的结果还是得自己听一下。遇到典型的声音顺手存进库里，之后也就不用再重新找例子了。

## 用起来

去 [Releases](https://github.com/Fantasy-Dm/ihearit/releases/latest) 下载 Windows 完整包，解压后运行 **ihearit.exe**。

选工程、选音轨，然后新建样例库。跟着引导听几段、分好类，就可以开始扫描了。具体范围直接拖波形，想从哪里听就点哪里。

如果是下载源码，双击 **setup-and-start.bat** 就行，脚本会准备对应版本的 Node.js 和 npm 依赖，第一次需要联网。仓库里就不塞这些东西了。

另外，Kdenlive / FFmpeg 需要自己安装。没自动找到的话，在“工具与设置”里手动选一下 `ffmpeg.exe`，同目录也得有 `ffprobe.exe`。

声音分析在本地进行，样例库和缓存放在程序目录的 `data` 里。
